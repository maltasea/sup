# PLEAC Everyday Capability Gaps (SUP)

Date: 2026-02-21

## 1) Goal

This report is not about conversion mechanics.  
Its purpose is to identify what everyday scripting capabilities are still missing in SUP.

## 2) Scope

Out of scope by decision:
- missing Perl module dependencies
- sections that fundamentally require Perl reference/coderef semantics

Reference-required sections excluded:
- `pleac/Chapter_11_References_and_Records/Section_11.4`

## 3) What SUP Already Covers Well

Current runtime already has strong daily primitives:
- text basics: `concat`, `split`, `join`, `upper`, `lower`, `length`
- regex read ops: `matchrx`, `extract`
- arrays/dicts: create, read, push/pop, map/filter/grep
- files/dirs: `read-file`, `write-file`, `append-file`, `read-dir`, existence checks
- paths: basename/dirname/join/type checks
- process: `run`, `pipe`, `sh`
- system bridge: `sys(...)` for POSIX/perl-call capabilities

## 4) Missing Everyday Capabilities (Ranked)

Ranking prioritizes common scripting frequency and practical pain.

| Rank | Missing capability | Why it matters daily | Primary chapter evidence |
|---|---|---|---|
| 1 | Regex substitution primitive (`replace` / global replace) | Text normalization and cleanup workflows need transform, not just match | Chapter 1 (`1.7`, `1.8`, `1.11`, `1.13`, `1.14`) |

## 5) Chapter-Specific Discussion (Your Priority: 1 and 7)

### Chapter 1 (`Chapter_01_Strings`)

Main actionable gaps:
- substitution/transformation regex operations
- robust trim/indent/wrap helpers
- safe interpolation replacement for `eval`-style snippets
- optional byte-oriented text tools (`pack`/`unpack` equivalents)

Most important feature additions for Chapter 1:
1. `text->replace(text, rx, repl)`
2. `text->replace-all(text, rx, repl)`
3. `text->trim / text->ltrim / text->rtrim`
4. `text->wrap(text, width)`
5. `text->indent(text, n)` / `text->dedent(text)`

### Chapter 7 (`Chapter_07_File_Access`)

Main actionable gaps:
- temp/atomic/lock workflow ergonomics
- globbing and multi-file iteration utilities
- fd-level and nonblocking primitives (advanced tier)

Most important feature additions for Chapter 7:
1. `file->temp()` / `dir->temp()`
2. `file->atomic-write(path, text)` (temp + fsync/rename semantics)
3. `file->lock(path, mode)` / `file->unlock(handle)`
4. `dir->glob(pattern)` and optional recursive walk
5. (advanced) fd dup/redirection and nonblocking read/write

## 6) Suggested Backlog Order

Phase A (highest daily value, lowest complexity):
1. regex substitution helpers
2. trim/wrap/dedent string helpers
3. temp + atomic write helpers

Phase B (high value, medium complexity):
1. locking helpers
2. glob/walk helpers
3. safe template engine (explicit placeholders, no eval)

Phase C (advanced/system-level):
1. fd dup/redirection model
2. nonblocking/select wrappers
3. binary pack/unpack compatibility layer

## 7) Success Criteria

This report is successful when each remaining PLEAC blocker can be labeled as one of:
- `missing_sup_feature` (real runtime gap)
- `snippet_noise` (cookbook fragment, not a language/runtime gap)
- `out_of_scope` (module dependency or reference-required semantics)

Only `missing_sup_feature` should drive SUP roadmap work.
