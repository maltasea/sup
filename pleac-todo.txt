## Guardrails (Do Not Break Interpreter)

1. Keep parser changes out unless strictly required.
2. Land one small feature per change.
3. Update tests in the same change.
4. Prefer small runtime helpers over deep runtime rewrites.
5. If regression risk appears, stop and report before continuing.
